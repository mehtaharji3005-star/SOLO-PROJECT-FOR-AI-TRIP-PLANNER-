# SOLO-PROJECT-FOR-AI-TRIP-PLANNER-
Here's a version within **350 characters**:  AI Trip Planner is a Python-based application that uses Google Gemini AI, LangChain, and Google APIs to create personalized travel itineraries. It generates day-wise plans based on budget, dates, interests, preferences, with weather and location details. Users can export the itinerary as PDF or TXT.
